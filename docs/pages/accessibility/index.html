נגישות באתר

חשוב לי שתוכלו לגלוש באתר בנוחות, להכיר את המפגשים ולמצוא את המשחקים והמידע שאתם צריכים.

כלי עזר לגלישה

כפתור הנגישות הצף בצד המסך פותח אפשרויות להגדלת הטקסט, לניגודיות גבוהה ולהדגשת קישורים. אפשר לבחור את ההתאמות שמתאימות לכם ולבטל אותן בכל שלב באמצעות „איפוס התצוגה”. הבחירה נשמרת בדפדפן שלכם.

האזנה למאמרים

בתחילת כל מאמר יש אפשרות להקראה, עם השהיה, המשך, עצירה ובחירת מהירות. ההקראה זמינה במכשירים ובדפדפנים שבהם מותקן או זמין קול בעברית.

שימוש במקלדת ובהגדלת התצוגה

  • אפשר לעבור בין קישורים וכפתורים בעזרת Tab, ולחזור אחורה בעזרת Shift + Tab.
  • להפעלת קישור לחצו Enter. להפעלת כפתור אפשר להשתמש גם במקש הרווח.
  • הקישור „דלגו לתוכן” בתחילת העמוד מאפשר להגיע ישירות לתוכן הראשי.
  • לסגירת חלון פתוח אפשר להשתמש בכפתור הסגירה או במקש Escape.
  • באזורים שבהם התמונות או ההמלצות מתחלפות אוטומטית, אפשר לעצור אותן בכפתור „השהיה”.
  • להגדלה נוספת אפשר להשתמש בכלי ההגדלה של הדפדפן. במחשב: Ctrl + +, וב־Mac: Command + +.

מידע מתוך תמונות וסרטונים

לצד צילומי ההמלצות מופיעים קטעים נבחרים בטקסט. אם תרצו לקבל את שאר המידע שבצילום, או אם קשה להשתמש בסרטון או בפעילות באתר חיצוני, מוזמנים לפנות אליי ואעזור לקבל את המידע.
