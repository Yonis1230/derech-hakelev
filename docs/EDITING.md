# עריכת אתר דרך הכלב
האתר נשאר אתר סטטי בתיקיית docs, עם אותם שני נתיבים ואותו CNAME.

## תוכן ותמונות
- index.html: טקסט עמוד הבית, קצת עליי, שירותים ויצירת קשר.
- pages/games/index.html: פתיחת הקטלוג, המבצע והאזורים המשותפים.
- catalog.js: רשימת המוצרים. לכל מוצר id קבוע, name, summary, price, outOfStock, tag, images ו-details (הסבר מלא ב-HTML עם סרטונים וקישור להזמנה).
- מחיר שלא קיים במקור נשאר null. אין להוסיף מחיר או פרטי מוצר ללא מידע מאומת.
- images מכיל נתיבים יחסיים לתיקיית docs, עם לוכסנים /. הגלריה מתאימה את מספר החצים והמונה למספר התמונות ומציגה אותן בשלמותן.
- DERECH_HOME_IMAGES בסוף catalog.js מכיל את תמונות הפעילות הקיימות.
- styles.css: צבעים, טיפוגרפיה ומבנה רספונסיבי.
- scripts.js: בניית הכרטיסים, גלריות ופתיחת פרטים.
- pages/games/game1.js: משחק התאמת בעיות ופתרונות עם מקלדת וכפתור משחק חדש.

## תצוגה מקדימה ופרסום
יש להגיש את docs דרך שרת קבצים מקומי (למשל Live Server ב-VS Code) ולבדוק / ו-/pages/games/.
התצוגה שהוכנה בסשן הנוכחי: http://localhost:4173/
השרת המקומי זמני; אפשר להפעילו שוב באמצעות Live Server.
צילומי התצוגה מחוץ לתיקיית docs, ב-artifacts/preview.
לפני פרסום יש לבדוק את שני העמודים במחשב ובנייד, דפדוף, פרטים, קישורי ההזמנה וסרטונים.
אין לפרסם או לדחוף ל-main לפני אישור יוני.

## מקור הנתונים
המחירים, מצבי המלאי, ההסברים, הסרטונים וקישורי הפעילויות הועתקו מהקבצים המקומיים המקוריים.
מחירים: שבעה משחקי מארז ב-165 ₪; תיבת בריחה 35 ₪; חוברת דיגיטלית 75 ₪.
עולם הכלב, רגשות מעורבים ומארז דרך הכלב חזרו למלאי לפי עדכון יוני. תיאוריהם ומחיריהם שוחזרו מהגרסאות שלפני הודעות אזילת המלאי ב-Git: 5c7e5b9^, e81979e^ ו-3ad2de6^ בהתאמה.
מבצע המארזים מוצג פעם אחת בלבד; בונוסים ייחודיים נשארו בהסברים.
קישורי WhatsApp הוסבו ל-wa.me עם אותו מספר ותוכן ההודעה, לשימוש במחשב ובנייד.
