# עריכת אתר דרך הכלב
האתר נשאר אתר סטטי בתיקיית docs, עם אותם שני נתיבים ואותו CNAME.

## תוכן ותמונות
- index.html: טקסט עמוד הבית, קצת עליי, שירותים ויצירת קשר.
- pages/games/index.html: פתיחת הקטלוג, המבצע והאזורים המשותפים.
- catalog.js: רשימת המוצרים. לכל מוצר id קבוע, name, summary, price, outOfStock, tag, images ו-details (הסבר מלא ב-HTML עם סרטונים וקישור להזמנה).
- מחיר שלא קיים במקור נשאר null. אין להוסיף מחיר או פרטי מוצר ללא מידע מאומת.
- images מכיל נתיבים יחסיים לתיקיית docs, עם לוכסנים /. הגלריה מתאימה את מספר החצים והמונה למספר התמונות ומציגה אותן בשלמותן.
- DERECH_HOME_IMAGES בסוף catalog.js מכיל את תמונות הפעילות הקיימות.
- styles.css: צבעים, טיפוגרפיה ומבנה רספונסיבי.
- scripts.js: בניית הכרטיסים, גלריות ופתיחת פרטים.
- pages/games/game1.js: משחק התאמת בעיות ופתרונות עם מקלדת וכפתור משחק חדש.

## תצוגה מקדימה ופרסום
יש להגיש את docs דרך שרת קבצים מקומי (למשל Live Server ב-VS Code) ולבדוק / ו-/pages/games/.
התצוגה שהוכנה בסשן הנוכחי: http://localhost:4173/
השרת המקומי זמני; אפשר להפעילו שוב באמצעות Live Server.
צילומי התצוגה מחוץ לתיקיית docs, ב-artifacts/preview.
לפני פרסום יש לבדוק את שני העמודים במחשב ובנייד, דפדוף, פרטים, קישורי ההזמנה וסרטונים.
אין לפרסם או לדחוף ל-main לפני אישור יוני.

## תמונות מהירות באתר
התמונות המקוריות נשארות ב-assets/images. אחרי הוספה או החלפה של תמונה יש להריץ משורש המאגר: node tools/optimize-dog-images.cjs. בסביבת העבודה הזו אפשר להשתמש ב- .tools/node-v22.23.3-win-x64/node.exe במקום node.
הפקודה יוצרת עותקים קלים ב-docs/assets/optimized ומעדכנת את docs/media.js. אין לערוך ידנית קבצים אלו. הנתיבים בגלריות נשארים ב-catalog.js כרגיל. תמונה חדשה בלי עותק קל תוצג מהמקור עד הרצת הפקודה.
לוגו ותמונת החבילה: החליפו את קובצי המקור assets/images/brand/logo.png או assets/images/games/bundle.png והריצו את הפקודה. לצורך עדכון מטמון, העלו את גרסת media.js המוזכרת בשני קובצי ה-HTML; להחלפת הלוגו או תמונת החבילה יש להעלות גם את גרסת כתובת התמונה ב-HTML. שמרו והעלו גם את העותקים שנוצרו.

## שאלון לבחירת משחק
הכפתור עם data-game-advisor פותח שאלון מקומי בן ארבע שאלות. אפשר לבחור כמה מטרות, קבוצות גיל ומסגרות, ולאשר כל שאלה בכפתור המשך. בשאלת הפורמט בוחרים אפשרות אחת; בשאלת הגיל, ״עדיין לא בטוחים״ מבטלת גיל מסוים ולהפך. docs/advisor.js אחראי לתצוגה; docs/advisor-data.js מכיל את השאלות ואת ההתאמה לכל מוצר לפי מזהה המוצר ב-catalog.js. כשמוסיפים מוצר או משנים המלצת גיל או אופי פעילות, צריך לעדכן גם את FACTS בקובץ ההתאמה. המחיר, התיאור וקישור הפרטים מגיעים מהקטלוג הקיים.
לפי עדכון יוני: ״בשביל המחשבות״ מגיל 8 ומעלה; ״לכל בעיה פתרון״ לכל גיל. בחירה בכמה קבוצות גיל מאפשרת לקבל גם הצעה שמתאימה לחלקן, עם ציון מפורש של הגילים המתאימים. בחירה מתחת לגיל 4 בלבד מציגה רק התאמה שתועדה לכל גיל, לפי מטרת המפגש והפורמט שנבחרו.
אין בשאלון הזנת פרטים אישיים, שמירה מתמשכת של תשובות בדפדפן או שליחתן לשירות המלצות חיצוני. החלון מסומן למיסוך ב-Clarity. הקוד נטען רק אחרי לחיצה על הכפתור. אחרי שינוי קובצי השאלון יש לעדכן את מספר הגרסה בייבוא של advisor.js בתוך scripts.js ובייבוא של advisor-data.js בתוך advisor.js.
