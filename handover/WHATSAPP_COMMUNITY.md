# קבוצת הוואטסאפ המקצועית

השינויים מקומיים בלבד; לא בוצעו פרסום, commit או push.

## מקור משותף והפקת עמודים

הקישור, כל נוסחי ההזמנה וקישור הפוטר מרוכזים ב־`tools/whatsapp-community.cjs`.
אחרי שינוי מריצים לפי הסדר:

```text
node tools/build-article-pages.cjs
node tools/sync-whatsapp-community.cjs
node tools/build-article-pages.cjs --preview
```

מחולל המאמרים מוסיף את ההזמנה גם למאמרים חדשים. מחוללי המוצרים ודפי המידע יורשים את הפוטר מעמוד הבית. הסנכרון מעדכן את הפוטר בכל העמודים הקיימים. ההזמנה בעמוד המאמרים נמצאת אחרי הרשימה; בבית אחרי קרוסלת המאמרים; במאמר אחרי הטקסט והמקורות ולפני שיתוף, תגובות והמשך. קישורים נפתחים בחלון חדש עם הודעה לקורא מסך ו־noopener noreferrer.

## מדידה והשלמה ב־GTM

נעשה שימוש בנתב הקיים `docs/measurement.js`, ללא התקנת GTM/GA4 נוספת. בכפוף להסכמה, לחיצה דוחפת פעם אחת:

```js
{
 event: 'derech_event',
 derech_event_name: 'whatsapp_community_click',
 derech_event_params: {
  link_location: 'article', // או articles_index, home, footer
  page_path: '/pages/articles/therapy-through-games/',
  link_type: 'community_invite'
  // בנוסף שדות הקשר העמוד המסוננים של הנתב הקיים
 }
}
```

זהו אירוע לחיצה בלבד ואינו אישור להצטרפות. אין שליחת שאילתת URL, מקטע, טקסט קישור או פרטי משתמש. אין שליחת אירועי בדיקה מהשרת המקומי. בדפים שאינם משחקים, הקונטיינר נטען רק בלחיצה ולאחר הסכמה, ללא הפעלת מדידת צפיות או אינטראקציות אחרות.

החיבור המתועד הקיים ב־`handover/DERECH_GTM_GA4_SETUP.md` מסנן שמות אירועים ופרמטרים. כדי שהאירוע החדש יגיע ל־GA4, יש להתאים בחשבון את **אותו** טריגר ותג קיימים:

1. להוסיף `whatsapp_community_click` לרשימת השמות המאושרים בתנאי ה־Regex של `DERECH - Approved website event`.
2. ליצור שלושה משתני Data Layer Variable בגרסה 2: `derech_event_params.link_location`, `derech_event_params.page_path`, `derech_event_params.link_type`.
3. להוסיף לתג `DERECH - Website events` את הפרמטרים `link_location`, `page_path`, `link_type` עם המשתנים המתאימים, ללא ערכי ברירת מחדל. אין להוסיף תג לחיצה או הטמעה נוספת.
4. ב־Tag Assistant לבדוק קליק יחיד בכל מיקום, הפעלת תג אחת ופרמטרים נכונים; לאשר ב־GA4 DebugView. אין לסמן זאת כהצטרפות בפועל.
5. אם נדרש פילוח לפי מיקום בדוחות, לרשום את `link_location` ואת `link_type` כ־Custom dimensions בהיקף Event. לפרסם את שינויי החשבון רק לאחר בדיקה ואישור בעל האתר.

לא בוצע שינוי בחשבון GTM או GA4. בדיקות VM עברו עבור ששת הנתיבים המייצגים, הסכמה וביטולה, מניעת כפילויות, מארח שגוי ותצוגה מקומית. קבלת האירוע בשרת GA4 עדיין דורשת אימות בחשבון.

## מגבלת תצוגה

בדיקות מבניות של כל העמודים והקישורים עברו. כלי השליטה במחשב עצר משום שלא הצליח לזהות בבטחה את כתובת הדפדפן. לכן בדיקה חזותית במחשב ובמובייל ואימות מסך ההזמנה ב־WhatsApp לא הושלמו. יש לבצע אותן לפני פרסום.

בדיקות שהושלמו: בניית המאמרים הציבוריים והתצוגה המקומית; בדיקת עדכניות הבנייה (ללא הבדלים); בדיקות המאמרים, המוצרים וכל 26 עמודי האתר; 27 קבוצות בדיקות מדידת Google, ארבע קבוצות hooks ו־12 בדיקות הסכמה. בדיקת TypeScript של Studio עברה. בדיקת Astro של אתר אפרת הנפרד נשארה ללא פלט ולא הסתיימה, ולכן נעצרה; בניית Astro ו־Studio המלאה לא אומתה. לא שונה קוד של אתר אפרת. ניסיון לפתוח את קישור ההזמנה באמצעות כלי הרשת נכשל עקב מגבלת גישה של הכלי, ואינו מעיד שההזמנה פגה.
